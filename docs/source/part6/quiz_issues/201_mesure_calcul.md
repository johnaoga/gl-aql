### Question

Quelle est la différence entre **mesure** et **calcul** ?

### Options (for single/multiple choice only)

La mesure est indirecte, le calcul direct
Le calcul est une quantification indirecte obtenue à partir de mesures
Mesure et calcul sont synonymes
Le calcul nécessite toujours une unité SI

### Explanation (optional)

Mesure = quantification directe (ex. cm) ; calcul = quantification indirecte à partir de mesures (ex. 1 m = 100 cm).
